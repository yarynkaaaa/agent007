Інтелектуальний агент, який радить фільм або книжку за вашим настроєм

Агент розпитує про настрій, самостійно викликає інструмент підбору та розповідає про жанр і сюжет кожного твору. Нижче можна спробувати спрощене демо прямо в браузері.

Спробувати демо Код на GitHub

Демо

Оберіть настрій і тип твору. Кнопка «Ще варіанти» не повторює вже показане, як і параметр exclude в агенті.

Ваш настрій

Що шукаєте

Це демо працює без ШІ: воно використовує той самий каталог і ту саму логіку інструмента recommend. Розмова природною мовою доступна в повній версії агента (Python + LLM), див. розділ «Запуск».

Як працює агент

Модель не вигадує рекомендацій: вона вирішує, коли викликати інструмент, а назви, жанри й сюжети бере з каталогу.

1

З’ясовує настрій

Якщо користувач ще не сказав, як почувається, або не вказав фільм чи книжку, агент ставить уточнювальне питання.

2

Визначає категорію

LLM зводить вільні слова («сонна», «нудно») до одного з семи настроїв: сумний, радісний, втомлений, стресовий, нудьгую, романтичний, енергійний.

3

Викликає інструмент

Функція recommend(mood, kind, exclude) повертає до двох творів із жанром і коротким сюжетом, пропускаючи вже запропоновані.

4

Формує відповідь

Агент подає назву, жанр і опис сюжету. Якщо нового більше немає, чесно про це каже.

Технології

  • Python 3.12, бібліотеки openai і gradio
  • LLM через OpenAI-сумісний API (Groq, HuggingFace або OpenAI, перемикається змінною BACKEND)
  • Власний JSON-протокол викликів інструментів: модель повертає {"tool": …} або {"answer": …}
  • Веб-інтерфейс чату на Gradio

Скріншоти

Робота агента в браузері та в консолі.

Тестування

Сценарії, на яких перевірялася поведінка агента.

Запит Очікувана поведінка
«Привіт» Агент питає про настрій і тип (фільм/книжка), інструмент не викликається
«Мені сумно», потім «фільм» Виклик recommend з настроєм «сумний», два фільми з жанром і сюжетом
«Я втомився, порадь книжку» Настрій «втомлений», тип «книжка»
«Сонна» Вільне слово зведено до настрою «втомлений»
«Ще» / «Ще ідеї» Нова пара творів: уже показані передаються в exclude
Повторні «ще» після вичерпання каталогу Агент повідомляє, що нових творів більше немає

Запуск повної версії

Потрібен Python 3.10–3.13 і безкоштовний ключ Groq (console.groq.com). 

git clone https://github.com/yarynkaaaa/agent007.git
