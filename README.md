# 🎬 Агент-рекомендатор фільмів і книжок

Практична робота. «Розроблення та тестування інтелектуального агента на основі моделей штучного інтелекту», **варіант 14**.

Агент запитує про настрій користувача й радить фільм або книжку відповідного жанру. Для кожного твору показує **жанр і короткий опис сюжету**.

## Можливості

- з'ясовує настрій і тип (фільм чи книжка) уточнювальними питаннями;
- розуміє вільні формулювання («сонна», «нудно») і зводить їх до одного з 7 настроїв;
- викликає інструмент `recommend(mood, kind, exclude)`, який бере твори з каталогу;
- не повторює вже запропоноване, коли користувач просить «ще»;
- чесно повідомляє, коли нових творів у каталозі не залишилось.

## Як це працює

1. Користувач пише повідомлення в чаті (інтерфейс Gradio).
2. LLM отримує системний промпт і історію розмови та відповідає JSON-об'єктом:
   - `{"tool": "recommend", "args": {...}}`: потрібен виклик інструмента;
   - `{"answer": "..."}`: фінальна відповідь або уточнювальне питання.
3. Код виконує інструмент, додає результат до діалогу й повертає його моделі.
4. Модель формує відповідь, використовуючи лише дані з каталогу, тому сюжети не вигадуються.

Підтримувані backend-и (змінна `BACKEND`): `groq` (безкоштовно), `hf` (HuggingFace), `openai`.

## Обмеження

- Каталог невеликий: 12 творів (6 фільмів і 6 книжок).
- Безкоштовні моделі інколи не передають `exclude` або відповідають не JSON-ом, тоді запит варто повторити.
- Сайт на GitHub Pages містить лише демо без ШІ. Агент із LLM запускається локально.
